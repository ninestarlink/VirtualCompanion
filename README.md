# 小汐 · 伴侣小生命情绪互动 + 状态调试面板

居家实战测试交付：一个精致的单页互动 Web 应用。页面核心是一条有"呼吸生命感"的 Live2D 伴侣角色「小汐」，支持中文对话与快捷互动，角色会随语义切换 4 种情绪状态（待机呼吸 / 开心雀跃 / 害羞脸红 / 犯困打盹），背景光影氛围随心情同步平滑变化；右侧附一个「状态监控与远程调试台」。

## 功能对照

- [x] 核心互动画面：Live2D 模型渲染（视线跟随鼠标、眨眼、呼吸、物理摆动、待机动作）
- [x] 角色部位互动：点头部 → 摸头（开心 + 语音回应）、点身体/脚 → 痒（害羞），点空白背景不误触
- [x] 待机小动作：空闲 9–18 秒随机播一段动作；拖拽角色可左右挪动，松手弹性归位
- [x] 底部 1 个文字输入框 + 3 个快捷互动按钮（摸摸头 / 夸夸她 / 哄她睡觉）
- [x] 至少 4 种情绪状态切换，表情 + 灯光主题 + 背景微动效同步平滑过渡
- [x] 大模型语义判断（GLM-4-Flash 免费额度），不可用时自动降级为本地情绪路由
- [x] **全链路流式**：SSE 逐字打字机输出，情绪标记先于正文推送（第一时间切换表情/灯光），语音分句合成边生成边播
- [x] 萌妹语音对话：回复自动朗读（默认 Edge 晓伊，可切换本地「鸣潮·菲比」音色），麦克风语音输入（点一次开麦、再点一次结束，边说话边实时转成文字），一键静音
- [x] 开发者调试台：实时情绪状态码、互动历史日志、强制切换动作状态、切换场景灯光主题色、发送系统提示气泡
- [x] iPhone 风格 UI（毛玻璃 / 灵动胶囊 / 弹簧动效），手机端自适应，全中文界面
- [x] 聊天栏可折叠：右上角小圆钮一键收起为一枚小胶囊，不再遮挡角色；再点一下展开

## 启动方式

### 方式一：一条命令跑全栈（推荐）

```bash
# 1. 安装后端依赖（仅 fastapi + uvicorn）
cd backend
pip install -r requirements.txt

# 2. 配置密钥
copy .env.example .env    # 然后在 .env 中填入你的智谱 API Key
# Linux/Mac 使用: cp .env.example .env

# 3. 构建前端（首次或前端有改动时执行一次）
cd ../frontend
npm install
npm run build

# 4. 回到根目录，一条命令启动（后端同时托管前端页面）
cd ..
python backend/main.py
```

浏览器打开 http://127.0.0.1:8600 即可。

### 方式二：前端开发模式（热更新）

```bash
# 终端 1
python backend/main.py

# 终端 2
cd frontend
npm run dev
# 打开 http://localhost:5173（已配置 /api 代理到 8600）
```

## 说明

- **密钥安全**：API Key 仅通过后端环境变量读取，前端代码零密钥；`.env` 已加入 `.gitignore`，仓库只提交 `.env.example`。
- **降级策略**：大模型不可用（网络/额度/未配置）时，`/api/chat/stream` 自动切换到本地关键词情绪路由（模拟流式分片），功能不中断；`/api/chat` 保留为聚合格式的兼容端点。
- **流式协议**：SSE 三种事件——`emotion`（情绪标记，先于正文推送）、`delta`（正文增量，前端打字机累加）、`done`。模型按「第一行情绪标记 / 第二行回复正文」的协议输出，后端边收边解析。
- **流式语音**：前端按句末标点实时切句入队，逐句调用 `/api/tts` 边生成边播放，不等全文合成完毕；静音会清空队列并立即停止当前句。
- **萌妹语音**：`/api/tts` 默认走 Edge 在线 TTS 的晓伊音色（`zh-CN-XiaoyiNeural`）；把 `TTS_ENGINE` 改成 `genie` 可切换为本地 Genie-TTS 的「鸣潮·菲比」（模型放在 `backend/models/genie`，已 gitignore，CPU 推理较慢）。本地音色合成失败会自动回退 Edge。语音输入用服务端 SenseVoiceSmall（不支持录音时回退浏览器 Web Speech API）。
- **渲染内核**：`pixi.js 8` + `untitled-pixi-live2d-engine`（Cubism 5 管线）。早期接入的是 `pixi-live2d-display@0.4`（Cubism 4 管线），它不支持逐网格乘法色，而本模型的鼻子阴影正是用乘算色做的，于是被画成一整块实心黑块。换到 Cubism 5 内核后由引擎原生正确处理，不需要隐藏部件之类的补丁。
- **首次加载**：模型约 60MB（含 16MB moc3），已做加载态提示与素材本地托管，浏览器缓存后二次打开秒开。
